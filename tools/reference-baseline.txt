## Excluded from this run: tests/test_bin.py

Those tests import madmom's bin/* programs in-process and run them with `batch -j 1`,
which starts a multiprocessing pool. Inside the sandbox (bubblewrap with an isolated
IPC namespace) the workers block on a semaphore forever — the first full run hung at
26 % and was stopped; pytest-timeout later pinned it to
`multiprocessing/synchronize.py: wait` via tests/test_bin.py::run_batch. On a normal
host these tests should run, so `./tools/build_reference.sh` includes them.
